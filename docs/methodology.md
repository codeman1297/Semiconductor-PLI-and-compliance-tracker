# Research methodology

## Inclusion
A record represents a material India-based semiconductor manufacturing, assembly, testing, packaging, design, materials, equipment, display, or supporting facility/project. A public project requires one or more accessible sources.

## Evidence and confidence
Tier 1 sources (government releases/filings and official company disclosures) normally support **High** confidence. Tier 2 state releases and investor presentations can support **Medium** confidence. Credible reporting supplies context but is not automatically treated as fact. **Low** confidence means information needs verification.

## Status and conflicts
Overall status is the current best-reviewed summary; milestones independently represent approval, land, construction, equipment, and production stages. Conflicting figures remain in their linked sources. Reviewers select the current value using source quality, publication date, and explicit disclosure, adding notes rather than erasing disagreement.

## Freshness
`last_verified_at` is the most recent date a reviewer checked the record’s public evidence, not necessarily the date of the underlying event. Unknown values are displayed as undisclosed.
